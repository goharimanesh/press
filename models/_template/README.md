# Model template

1. Copy this folder to `models/<your-model-id>` (lower-case, dashes, no spaces).
2. Replace `index.html` with the simulation.
3. Add `cover.svg` (or .png/.jpg, 16:10, e.g. 800×500) for the gallery card.
4. Optional: add `podcast.mp3` (or .m4a .aac .ogg .opus .wav .webm). It is detected automatically.
5. Add an entry to `models/registry.js` with the same `id`, the lab (`arcslab` or `sss`), title, authors, abstract, features and tags.

The `_template` folder is not listed in the gallery because it is not in the registry.
